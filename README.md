# Kotlin-Hoon-Migration

Analysis documents proposing a migration from React/React Native to Kotlin
Multiplatform (KMP) with a Hoon-philosophy formal verification layer, plus a
companion ROI report on AI documentation and reliability. These are proposal
and analysis documents — there is no Kotlin or Hoon source code in this
repository.

## Contents

- **`React_to_Kotlin_Value_Analysis.docx`** — *"From React to Kotlin/KMP: A
  Cross-Enterprise Value Analysis, With Hoon-Philosophy Formal Verification
  Layer"* (February 2026). A cost-benefit analysis of migrating large React
  codebases to KMP with a formally verified kernel (Lean 4 / Kotlin type
  system, strangler-fig migration pattern). Marked by its author as a proposal
  for a compensated engagement, shared for evaluation purposes.

- **`AnthropicROI.docx` / `AnthropicROI.pdf`** — the *Anthropic ROI* report
  (same document, two formats): a value and information-architecture analysis
  addressed to Anthropic, including a discoverability audit of the Claude
  Terms of Service and a proposed research engagement. Footer notes it was
  produced with Claude.

- **`Screenshot_20260317-111353.png`** — screenshot of a related X post by
  the author (March 2026).
